# G0 and G1

Recorded 29 October 2026 on branch `dimetric-30-v1`.

## Baseline, before the camera change

- HEAD `59b07fb6d3af939c48362e2edeeda0b3543c053f` (`Release v0.12.2`). The working tree already had uncommitted table-account, talk, and ring work. That work was kept.
- Locked client versions: Svelte 5.57.2, Vite 8.3.5, Vitest 4.1.12, Three.js 0.186.1. The server crate is edition 2024. Nothing was upgraded.
- `cargo test --manifest-path server/Cargo.toml`: 127 passed, 0 failed.
- `cd client && npm test`: 23 files, 46 tests passed, 0 failed.
- No test reads or writes `data/state.json`. The migration fixture is `server/tests/fixtures/v1-mixed.json`, loaded only into a temp directory.

## G0 result

- Diagnostic pictures are generated in `client/src/lib/render/fixtures/` and checked for stable bytes.
- `cd client && npm run smoke` serves `smoke.html` and opens headless Chromium with SwiftShader. The page must print `SMOKE_OK` and writes `docs/milestones/g0-smoke.png`.
- That run printed `SMOKE_OK`. The picture is a diamond ground with a raised red marker, a holed cutout, a cast silhouette, and two axis marks. It is a diagnostic render, not production art.

## G1 result

- The scene camera is only `dimetric-30-v1` (30° elevation, 45° azimuth, south-west of the focus). `cameraProfile.test.ts` checks the basis, the 2:1 cell, equal ground-axis lengths, project/pick on tiers 0, 1, and 2, pan, cursor-centered zoom, and docked framing.
- Turn and lighting controls are gone from the view bar. `turnView` does not change the view. An old angled picture stays stored and is not drawn; the table warns once and uses the fixed view.
- New scenes are marked `schema_version: 1` and `visual_profile: dimetric-30-v1`. An old scene file still loads, with an empty profile. Layout `levels` is absent, which means tier 0.
- After these changes: server tests 128 passed. Client tests 54 passed, including the new camera and fixture tests.

## Not done yet

Tiles, objects, cast, outlines, stairs, height-aware sight, save migration to a new version, and the acceptance scene are still ahead. The engine still picks the flat ground plane. Standees use the new cutout scale, but their footprint anchor is still the old front-left point. The asset guide below its opening note still describes the retired 53° contract.
