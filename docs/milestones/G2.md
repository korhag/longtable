# G2 — versioned pack import

Recorded 2026-10-29 against the working tree on `dimetric-30-v1`.

## What a GM can do

Import a schema-2 zip from Map → Import pack. The library lists Tiles, Objects, and Cast. A bad archive installs nothing. One broken pack on disk does not hide a good one. An imported id is kept: the same bytes can be imported again, and different bytes under that id are refused.

The catalog revision is a small counter, starting at 1. An import advances it, and every connected seat gets that number on the next snapshot.
