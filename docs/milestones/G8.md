# G8 — Height-aware sight

An eye is 1.0 above the square it stands on. A figure is sampled at 0.8 above its square. The ground is solid below its surface. A blocker counts only between its base and its top.

A wall or closed door with no authored volume is 8 units tall, measured from the higher square beside it. An object `visionVolume` keeps the height written in the pack. Flat maps with no volumes and no raised squares still use the old visibility polygon.

## Tests

`cargo test` from `server/`: 157 passed. That includes:

- A tier-2 eye clears a wall of height 0.5 and does not clear a wall of height 4.
- The floor sample can be hidden while the figure sample on the same square is seen.
- A tier-2 ridge hides the far side.
- A player snapshot includes the far figure over the low hedge and omits it after the hedge is raised to 4. The same snapshot carries current visible cells, and a flat wall still hides an adversary.
- 200 sight checks on a 12×12 map stayed under 500 ms in a debug build. The mask is cached until a token, door, wall, or height changes, so a dice roll does not recompute it.

`npm run check` and `npm test` in `client/`: 0 errors, 62 passed.
